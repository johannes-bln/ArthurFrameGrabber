# Frame Grabber (Fork)

This repository is a **non-commercial fork** of [Frame Grabber](https://framegrabberapp.com), an iOS & iPadOS app that extracts full-resolution video frames as images — [framegrabberapp.com](https://framegrabberapp.com)

> **Note**  
> This fork exists **only for personal learning and experimentation**.  
> It is **not** affiliated with or endorsed by the original developer or the new app owner.  
> **Do not publish** this fork or any derivative on the App Store.

---

## Original Project

The original Frame Grabber was created by [Arthur Hammer](https://github.com/arthurhammer) and published on the App Store until version **1.4.1**.  
As of June 2023, Frame Grabber has been **acquired** and is now maintained by a new owner.

You can find the original repository here:  
👉 [github.com/arthurhammer/FrameGrabber](https://github.com/arthurhammer/FrameGrabber)

---

## Purpose of This Fork

This fork is meant for:
- Understanding how an iOS video frame extraction app works  
- Exploring UIKit, MVC architecture, and Apple’s AVFoundation APIs  
- Experimenting locally with modifications or new ideas

No commercial use intended.

---

## How to Build

1. Open the project in **Xcode**
2. Change **Development Team** and **Bundle Identifier**
3. Build and run on a device or simulator

---

## Project Structure

- [`Application`](Frame%20Grabber/Application): App entry point  
- [`Scenes`](Frame%20Grabber/Scenes): Main screens  
- [`Packages`](Frame%20Grabber/Packages): Extracted modules  

This project follows **MVC** and **storyboards**, as it was designed to learn the basics of iOS development.
